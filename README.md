# 📰 The Fact  
> 카테고리 기반 뉴스 기사 웹 서비스  

<br/>

## 📌 프로젝트 소개

**The Fact**는 카테고리별 뉴스 기사 조회 및 댓글 기능을 제공하는 웹 서비스입니다.  
대량 데이터 환경에서도 안정적인 조회가 가능하도록 **페이징 처리 및 데이터 구조 설계**에 중점을 두었습니다.

사용자는 정치 · 경제 · 사회 · 연예 · 스포츠 등 다양한 카테고리의 뉴스를 열람할 수 있으며,  
댓글을 통해 기사에 대한 의견을 자유롭게 남길 수 있습니다.

## 🚀 트러블 슈팅

### 📌 문제 1 – 댓글 대량 조회 시 성능 저하
**원인:** 전체 댓글을 한 번에 조회  
**해결:** 페이지네이션 적용 + LIMIT 기반 쿼리 최적화  

### 📌 문제 2 – 비동기 댓글 처리 오류
**원인:** Ajax 응답 데이터 구조 불일치  
**해결:** DTO 구조 재정리 및 REST 응답 통일
